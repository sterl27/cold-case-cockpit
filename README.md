# Cold Case Cockpit

Liquid Noir production desk for Flame Pro / Cold Case.

- 32-bar writer (4 octets) with take drawer
- 72 BPM 8-bar drum grid
- Chop lab (VERSE / HOOK / BREAK)
- Four-block STYLE / META / NEGATIVE / MACHINE
- Boom-bap vs Flame Pro A/B

## Run

```bash
cd cold-case-cockpit
npm install
npm run dev
```

Open http://localhost:3000

Lock: 72 BPM, D minor (estimated), mono piano, distorted 808, orchestra on lift only. Master –9 LUFS / –1 dBTP. No artist names in export labels.
